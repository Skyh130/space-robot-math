# 우주 로봇 수학 모험 — 설계서

초등 2학년 → 3학년 수학 학습용 웹 게임 설계 문서
대상 기기: 태블릿 + 스마트폰 (세로 모드)

---

## 1. 콘셉트

흩어진 로봇 부품을 찾아 우주를 여행하는 모험 게임.
행성(월드) 하나를 클리어할 때마다 부품 1개를 획득하고, 8개를 모두 모으면 최종 합체.

- 1회 플레이: 10~15분
- 1스테이지: 문제 8개 + 짧은 컷씬
- 전체 클리어: 약 6~8주 분량
- 별 기준: 정답 6개↑ ★ / 7개↑ ★★ / 8개 ★★★

> 저작권 문제를 피하기 위해 기존 로봇 IP의 이름·디자인은 사용하지 않고 오리지널 로봇으로 제작한다.

---

## 2. 월드 구성

| # | 월드 | 학습 주제 | 학년 | 획득 부품 |
|---|---|---|---|---|
| 1 | 숫자 소행성대 | 세 자리·네 자리 수, 자릿값 | 2-1, 2-2 | 헤드 유닛 |
| 2 | 중력 협곡 | 덧셈과 뺄셈 (받아올림/내림) | 2-1, 3-1 | 왼팔 |
| 3 | 에너지 코어 공장 | 곱셈구구 | 2-2 | 오른팔 |
| 4 | 관제 스테이션 | 시각과 시간 | 2-2, 3-1 | 부스터 |
| 5 | 구조물 격납고 | 평면도형, 길이 | 2-1, 3-1 | 몸통 |
| 6 | 암흑 행성 | 나눗셈, 두 자리 곱셈 | 3-1 | 왼다리 |
| 7 | 액체 행성 | 분수와 소수 | 3-1 | 오른다리 |
| 8 | 적 모선 | 표·그래프, 규칙, 종합 | 3-2 | 메인 웨폰 → 합체 |

각 월드 = 일반 스테이지 5개(Lv1~Lv5) + 보스전 1개

## 3. 난이도 설계 (3중 구조)

### ① 진도 난이도
월드 순서 자체가 2학년 → 3학년으로 상승.

### ② 스테이지 내 단계 (Lv1~Lv5)
같은 주제 안에서 조작 방식과 수의 범위를 단계적으로 확장.

### ③ 숨은 적응형 조절
- 최근 5문제 정답률 80% 이상 → 출제 난이도 +1
- 최근 5문제 정답률 40% 미만 → 출제 난이도 −1
- **이 변화는 화면에 절대 표시하지 않는다.** "쉬운 걸로 내려갔다"는 인식은 이 연령대의 가장 큰 이탈 요인.

### 오답 관리
- 처음 틀리면: 힌트 한 줄만. 답도 풀이 그림도 보여주지 않고 다시 풀게 한다
- 두 번째로 틀리면: 답과 풀이 그림을 편다. 그래도 정답을 직접 넣어야 넘어간다
- 같은 세션 내: 틀린 문제를 3문제 뒤에 숫자만 바꿔 재출제
- 다음 세션: '복습 문제'로 1~2개 자동 편성
- 영역별 정답률을 누적 기록해 취약 영역 우선 복습

## 4. 문제 출제 방식

문제를 개별 저장하지 않고 **템플릿 + 파라미터 자동 생성** 방식을 사용한다.
아이가 답을 통째로 외우는 것을 방지하고, 적은 설계로 무한한 문제를 확보할 수 있다.

```
템플릿: "{a}묶음에 {b}개씩 있으면 모두 몇 개?"
Lv1 파라미터: a, b ∈ 2~5
Lv4 파라미터: a, b ∈ 6~9
```

### 입력 방식 (문제 유형별로 다양하게)

| 방식 | 사용처 |
|---|---|
| 4지선다 | 모든 월드 Lv1~Lv2 |
| 숫자패드 입력 | 계산 문제 전반 |
| 탭 선택 / 골라내기 | 도형 분류, 그래프 읽기 |
| 드래그 | W4 시계 바늘, W5 도형 조립, W6 똑같이 나누기 **(이 3곳만)** |
| 순서 배열 | W1 크기 순 정렬, W8 규칙 찾기 |

> 모바일에서 정밀 드래그는 실패율이 높으므로 3개 영역으로 제한한다.

## 5. 문제 은행 상세

### W1. 숫자 소행성대 — 세 자리·네 자리 수

| Lv | 내용 | 파라미터 / 입력 |
|---|---|---|
| 1 | 세 자리 수 읽고 쓰기 | 100~999, 4지선다 |
| 2 | 자릿값 (472에서 7이 나타내는 값) | 백·십·일, 4지선다 |
| 3 | 뛰어 세기 빈칸 채우기 | 10씩·100씩, 3~5칸 |
| 4 | 네 자리 수 자릿값 + 크기 비교 | 1000~9999, 부등호 선택 |
| 5 | 숫자 카드로 조건에 맞는 수 만들기 | 카드 3~4장, 가장 큰/작은 수 |

**보스**: 흩어진 좌표 숫자를 크기 순으로 정렬해 항로 열기

---

### W2. 중력 협곡 — 덧셈과 뺄셈

| Lv | 내용 | 예시 |
|---|---|---|
| 1 | 두 자리 + 한 자리, 받아올림 없음 | 21 + 5 |
| 2 | 두 자리 ± 두 자리, 받아올림/내림 1회 | 37 + 45, 52 − 28 |
| 3 | 세 자리 ± 세 자리, 받아올림/내림 1회 | 245 + 132 |
| 4 | 세 자리, 받아올림/내림 2회 | 476 + 358, 502 − 167 |
| 5 | □ 있는 식 + 문장제 | 37 + □ = 62 |

**보스**: 계산식 3개를 순서대로 풀어 다리 3칸 복구 (시간 제한 없음)
**힌트**: 세로셈 애니메이션으로 받아올림 '1'이 올라가는 과정을 시각화

---

### W3. 에너지 코어 공장 — 곱셈구구

| Lv | 내용 | 입력 |
|---|---|---|
| 1 | 2·5단 | 4지선다 |
| 2 | 3·4·6단 | 숫자 입력 |
| 3 | 7·8·9단 | 숫자 입력 |
| 4 | 전체 섞기 + □ 채우기 (4 × □ = 28) | 숫자 입력 |
| 5 | 문장제 → 곱셈식 세우기 | 4지선다 + 입력 |

**보스**: 60초 안에 코어 12개 충전 — **전체에서 유일하게 타이머를 쓰는 구간** (구구단은 속도 자동화가 학습 목표)
**주의**: 7·8단 정답률이 낮으면 다음 세션 복습 문제로 자동 편성

---

### W4. 관제 스테이션 — 시각과 시간

| Lv | 내용 |
|---|---|
| 1 | 몇 시 몇 분 읽기 (5분 단위) |
| 2 | 1분 단위 읽기 |
| 3 | 시계 바늘 직접 돌려 맞추기 (드래그) |
| 4 | 시간 계산(40분 뒤), 오전·오후, 1일 = 24시간 |
| 5 | 초 단위, 시간표 읽고 계산 |

**보스**: 우주선 4대의 출발 시각표를 보고 가장 먼저/나중에 도착하는 배 찾기
**주의**: 아날로그 시계는 초2 오답률 최상위 영역. Lv3 드래그 조작 문항을 넉넉히 배치할 것.

---

### W5. 구조물 격납고 — 도형과 길이

| Lv | 내용 |
|---|---|
| 1 | 삼각형·사각형·원 분류 (탭 선택) |
| 2 | 변과 꼭짓점 개수 세기 |
| 3 | 자로 길이 재기 (cm, mm), 1cm = 10mm |
| 4 | 직각 찾기, 직각삼각형·직사각형·정사각형 구분 |
| 5 | 길이 계산 (2m 30cm + 1m 50cm), km 단위 |

**보스**: 조건에 맞는 부품 도형을 골라 로봇 몸통 조립

---

### W6. 암흑 행성 — 나눗셈과 곱셈

| Lv | 내용 |
|---|---|
| 1 | 똑같이 나누기 (구슬 12개를 접시 3개에, 드래그) |
| 2 | 나눗셈식 ↔ 곱셈식 관계 (구구단 범위 내) |
| 3 | 두 자리 × 한 자리 (올림 없음 → 있음) |
| 4 | 나머지가 있는 나눗셈 |
| 5 | 두 자리 ÷ 한 자리 세로셈 + 문장제 |

**보스**: "대원 27명을 4명씩 태우면 우주선 몇 대 필요?" (나머지 처리 사고 필요)
**힌트**: Lv1~2는 반드시 그림으로 먼저 보여준 뒤 식과 연결

---

### W7. 액체 행성 — 분수와 소수

| Lv | 내용 |
|---|---|
| 1 | 색칠된 부분을 분수로 나타내기 |
| 2 | 분수 읽기·쓰기, 단위분수 비교 (1/3 vs 1/5) |
| 3 | 분모가 같은 분수 크기 비교 |
| 4 | 소수 한 자리 읽기, 0.1 = 1/10 연결 |
| 5 | 소수 크기 비교 + 분수·소수 혼합 문장제 |

**보스**: 연료 탱크 3개 중 가장 많이 든 것 고르기 (분수·소수 혼합 표시)
**주의**: 전 월드 중 최고 난도. 시각 자료(막대·원 그래픽) 비중을 다른 월드의 2배로 배치.

---

### W8. 적 모선 — 자료와 규칙, 종합

| Lv | 내용 |
|---|---|
| 1 | 표 읽기 |
| 2 | 그림그래프·막대그래프 읽기 |
| 3 | 규칙 찾기 (수 배열, 도형 배열) |
| 4 | 흩어진 자료를 표로 정리하기 |
| 5 | 2단계 복합 문장제 (곱셈 → 뺄셈 등) |

**최종 보스**: 3라운드 구성
1라운드 계산 / 2라운드 도형·시간 / 3라운드 복합 문장제
클리어 시 부품 8개 합체 컷씬 → 엔딩. **게임 전체 보상의 정점이므로 연출에 가장 많은 공을 들일 것.**

## 6. 보상 구조

| 요소 | 내용 |
|---|---|
| 로봇 부품 | 보스 클리어 시 1개 획득. 격납고에서 조립 상태 확인 가능 |
| 별 1~3개 | 스테이지 정답률 기준. 재도전으로 별 올리기 가능 |
| 코인 | 문제 정답 시 획득. 로봇 컬러·데칼 구입에 사용 |
| 연속 출석 | 3일 연속 플레이 시 특별 부품 상자 |

### 60초 도전 (월드별)

보스를 깨면 그 월드에 열리는 놀이 구간. 60초 안에 그 월드에서 배운 문제를
섞어 내고, 맞힌 개수가 점수가 된다. 최고 기록만 남는다.

- 별도 부품도 주지 않는다. 진행에 아무 영향이 없다.
- 그래서 시간을 재도 학습에 방해가 되지 않는다. 배우는 스테이지는 그대로 둔다.
- 순서 배열 문제는 내지 않는다. 손이 느리면 아는데도 점수를 못 낸다.
- 별을 다 받은 뒤에도 다시 켤 이유가 된다. 기록은 계속 깰 수 있다.

### 패널티 정책
**체력 소진 후 처음부터 다시 하는 구조는 도입하지 않는다.**
오답 시 → 부드러운 피드백 + 한 줄 설명 + 그림 힌트 → 재시도.

## 7. UX 규격 (태블릿 + 스마트폰)

- **세로 모드 고정** (화면 회전 시 흐름 단절 방지)
- 문제 영역: 화면 상단 / 숫자패드: 화면 하단 (손이 문제를 가리지 않게)
- 버튼 최소 48 × 48 px
- 문제 텍스트 20px 이상, 숫자는 32px 이상
- 정답 피드백은 0.5초 이내 (효과음 + 애니메이션)
- 오답 시 정답만 알려주지 말고 **이유 한 줄 + 그림 힌트**
- 문제 읽어주기(TTS) 버튼 — 읽기 속도가 느린 아이 대응
- 기본은 타이머 없음 (W3 보스, 그리고 아래 60초 도전만 예외)
- 오프라인 동작, 진행 상황은 기기 로컬 저장

## 9. MVP 범위

### 1단계 — MVP (아이 반응 검증용)
- **월드 1~3만 구현** (수 개념 / 덧셈뺄셈 / 곱셈구구)
- 문제 생성 엔진 (템플릿 + 파라미터)
- 스테이지 Lv1~Lv5 + 보스전
- 별 획득, 부품 3개 획득 및 조립 화면
- 진행 상황 로컬 저장
- 오답 재출제 (같은 세션 내)

**제외**: 적응형 난이도, 코인 상점, 부모 대시보드, TTS, 컷씬 애니메이션

### 2단계
- 월드 4~8 추가
- 적응형 난이도, 세션 간 복습 큐
- 코인 상점 (로봇 컬러·데칼)
- 최종 합체 연출

### 3단계
- 부모 대시보드 (영역별 정답률, 오답 노트, 플레이 시간 제한)
- TTS 읽어주기
- 연속 출석 보상

## 10. MVP 검증 체크리스트

만든 뒤 아이에게 주고 다음을 관찰한다.

- [ ] 설명 없이 혼자 시작해서 첫 스테이지를 끝내는가
- [ ] 한 번에 몇 분을 하는가 (10분 미만이면 보상 밀도 부족)
- [ ] 다음 날 스스로 다시 켜는가 — **가장 중요한 지표**
- [ ] 틀렸을 때 표정이 어떤가 (좌절하면 힌트·난이도 재조정)
- [ ] 별 3개를 노리고 재도전하는가
- [ ] 부품 획득 순간에 반응이 있는가 (없으면 보상 연출 강화)

> 어른이 재밌을 거라 예상한 요소와 아이가 실제로 좋아하는 요소는 거의 항상 다르다.
> MVP로 먼저 검증하고 2단계 설계를 조정할 것.
